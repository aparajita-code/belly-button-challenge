# belly-button-challenge

***🧫 Belly Button Biodiversity Dashboard***
***📌 Overview***
This interactive dashboard explores the Belly Button Biodiversity dataset, cataloging microbial species (OTUs) that inhabit human navels. Built with D3 and Plotly.js, the application allows users to analyze sample data across individuals and observe the distribution of bacterial cultures through dynamic visualizations.

***🗂️ Repository Structure***
belly-button-challenge/
├── index.html
├── static/
│   ├── css/
│   ├── js/
│   └── images/
└── samples.json (reference only)
🔍 Features
Dropdown menu to select individual samples

Horizontal bar chart of the top 10 OTUs per sample

Bubble chart showing sample distribution across all OTUs

Dynamic demographic panel displaying individual metadata

Responsive layout powered by Plotly.js

*** 📊 Data Source***
samples.json (fetched via D3)
